# Personal CV website

A small static website designed for GitHub Pages. It uses plain HTML and CSS and has no build step.

## Personalise it

1. Open `index.html` and replace the placeholder name, role, city, introduction, experience, education, email, LinkedIn, and GitHub links.
2. Replace `cv.pdf` with your real CV, keeping the same filename.
3. Optionally replace `og.png` with a social preview that uses your real name.
4. Change the year in the footer when needed.

## Publish with GitHub Pages

1. Create a GitHub repository. Name it `YOUR-USERNAME.github.io` for a root personal site, or use any repository name for a project site.
2. Push every file in this directory to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will show the final site URL when deployment completes.
